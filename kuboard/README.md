# Kuboard

Kuboard is a Kubernetes management UI that provides an intuitive web interface for managing and monitoring Kubernetes clusters.

## Usage

```bash
cp .env.example .env
docker-compose up -d
```

## Access

- Web UI: http://127.0.0.1
- Default user: admin / Kuboard123

## Directory Structure

- `data/` - Data persistence
- `log/` - Log files
